The known failure mode of file-based template compilers, and the reason people bounce off Askama. Span map from generated byte ranges to .tri spans; `tri build` parses cargo's JSON diagnostics and re-renders them through miette against the original source.

- [ ] Generated code is never shown to the user in any error path
- [ ] Multi-span errors and suggestions survive the remapping
